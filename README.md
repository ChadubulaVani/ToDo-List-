# **Smart Task Planner**

**A modern, ultra-responsive To-Do List web app with advanced task management features, built using HTML, CSS and JavaScript.**

## **Features**

* **Add Tasks** with priority levels: High 🔴, Medium 🟡, Low 🔵
* **Priority-based color coding** with custom backgrounds for better visualization
* **Complete tasks** with smooth animated checkmarks
* **Drag & drop** to reorder tasks easily
* **Search & filter tasks** in real-time
* **Progress bar** showing task completion percentage
* **Dark & Light mode toggle**
* **Clear all tasks** with a single click
* **Fully responsive** – works perfectly on desktop and mobile devices
* **LocalStorage** – tasks are saved even after refreshing the page

---

## **Technology Stack**

* **Frontend:** HTML, CSS, JavaScript
* **Storage:** LocalStorage (browser)
* **Fonts:** Poppins (Google Fonts)

---

## **Installation / Usage**

1. **Clone the repository**

```bash
git clone https://github.com/ChadubulaVani/ToDo-List-
```

2. **Open `index.html`** in your browser

3. **Start adding tasks**:

   * Enter task name
   * Select priority (High / Medium / Low)
  * Click **“+”** button or press **Enter**

4. **Additional Actions:**

    Click **checkbox** to mark complete
    Drag & drop to reorder
    Use **search bar** to filter tasks
    Toggle **dark/light mode**
    Check **progress bar** to track completion
